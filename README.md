# 🚀 Projeto Fullstack - Gerenciador de Tarefas

Aplicação fullstack para gerenciamento de tarefas (To-Do List), permitindo criar, listar, atualizar e deletar tarefas em tempo real.

🔗 **Acesse o projeto online:**
👉 https://projeto-full-stack-orpin.vercel.app/

---

# 📌 Funcionalidades

* ✅ Criar tarefas
* 📋 Listar tarefas
* ✔️ Marcar como concluída
* ❌ Deletar tarefas

---

# 🛠️ Tecnologias utilizadas

### Frontend

* Next.js
* React
* Tailwind CSS

### Backend

* Node.js
* Express

### Banco de Dados

* PostgreSQL (Supabase)

### Deploy

* Vercel (Frontend)
* Render (Backend)

---

# 🧠 Arquitetura

```bash
Projeto_Fullstack/
  ├── backend/
  └── frontend/
```

# ⚙️ Como rodar o projeto localmente

## 1. Clonar o repositório

```bash
git clone https://github.com/seu-usuario/seu-repo.git
```

---

## 2. Backend

```bash
cd backend
npm install
npm run dev
```

---

## 3. Frontend

```bash
cd frontend
npm install
npm run dev
```
